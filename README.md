## 🚀 Getting Started

### Prerequisites
- Node.js / Modern Web Browser

### Setup & Run
1. Clone the repository:
   ```bash
   git clone https://github.com/shayann07/ClothPedia.git
   cd ClothPedia
   ```
2. Open in browser or local server:
   ```bash
   npx serve .
   ```
